# 05 Write Proposal

Write a proposal based on `request.md`, `summaries/`, and `reviews/review.md`.

## Tasks

- Save the proposal to `paperflow/<request-slug>/proposals/YYYY-MM-DD-<topic>.md`.
- Include source context used.
- Include literature basis.
- Include recommended plan.
- Include validation checks.
- Include risks, failure modes, and next experiments or decision steps.
- Mark missing evidence explicitly.
- Update `run-manifest.yaml` and `run-log.md`.

## Rules

- Do not modify implementation files.
- Recommend source code, config, data, or experiment changes only as proposals unless the request explicitly asks for edits.
- Ground recommendations in summaries and the review.
- Distinguish evidence-backed recommendations from speculation.

## Output

Commit the proposal and updated tracking files to GitHub.
